mRNNTorch
=========

mRNNTorch is a PyTorch library for building and analyzing multi-regional
recurrent neural networks. It provides model-building primitives for recurrent
and input regions, plus analysis tools for fixed points, linearization, flow
fields, and interactive flow visualization.

Start with the getting-started guide if you are new to the package. Use the API
reference when you need exact constructor arguments, method signatures, and
return values.
